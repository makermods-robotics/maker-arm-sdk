03 / WHAT TO LOOK FOR

Check the model

1. Parts and resting shape

In CAD zero, look for missing pieces, gaps, or misplaced parts. A different Star rest pose alone is not proof that the URDF is wrong.

2. Joint order and pivot

Move only the Star’s base joint a few degrees, then work toward the wrist. The matching row should change. All parts after that joint should move together around a shaft center, with no separation.

3. Direction and angle

Check that motion follows the expected direction. SDK mode scales Star angles; 1:1 mode does not. To verify accuracy, compare measured Maker joint angles at two or more poses. Matching one pose only tests an offset.

4. Dimensions and reach

Compare the displayed axis distances with the real Maker arm, using shaft centers. The Star is an input device; its link lengths need not match the Maker. Check tool position in several poses.

5. Limits and contact

Orange angles are outside the designer’s limits. This viewer shows the requested angle without clamping so mismatches remain visible. Turn on collision shapes to inspect contact surfaces; this viewer does not run collision detection.

6. Gripper and physics

Move the Star gripper gently. ID 6 should change and both jaws should slide equally in opposite directions. Check that fingers, carriages, and their collision shapes move together. Use Open model fully to inspect the 104.825 mm gap. This viewer cannot validate mass, friction, force, or inertia accuracy.
